1처음 열기 · 앱으로 설치

  1. 안내받은 캘린더 주소를 크롬이나 엣지로 열어요.
  2. 처음 열면 홈 화면에 "처음 오셨네요" 안내가 나와요. 3장 순서대로 내 시간표부터 넣으면 돼요.

앱처럼 설치하기 (추천)

  1. 주소창 오른쪽의 설치 아이콘(모니터에 화살표 모양)을 눌러요.
  2. 바탕화면·시작 메뉴에 학교 캘린더 아이콘이 생기고, 브라우저와 따로 열려요.

컴퓨터를 켤 때 자동으로 열기

크롬주소창에 chrome://apps 입력 › 학교 캘린더 아이콘 오른쪽 클릭 › 로그인 시 앱 시작
엣지주소창에 edge://apps 입력 › 학교 캘린더의 … › 장치 로그인 시 자동 시작
브라우저 첫 화면브라우저 설정 › 시작 그룹(시작할 때) › 특정 페이지 열기 › 캘린더 주소 추가

2화면 둘러보기

홈오늘 날짜·요일·시계, 방학까지 D-day, 지금 몇 교시인지, 오늘 일정, 다가오는 일주일, D-day, 구글 검색, 바로가기, 자료함
일하루 시간표(바뀐 칸은 색으로 표시)와 그날의 학교 일정·내 일정
주월~금 시간표 전체와 학교 일정·내 일정을 한눈에
월한 달 달력. 날짜를 누르면 하루 보기, 빈 곳을 누르면 일정 추가
연간학사일정과 공휴일. 수업 없는 날은 빨간 줄

왼쪽 목록에서 보고 싶은 것만 켜고 끌 수 있어요: 내 시간표, 학사일정, 월중 행사계획, 주간계획, 공휴일, 부서별 보기, 내 일정 카테고리.

키보드: ←→ 이전·다음, T 오늘, D·W·M·Y 일·주·월·연간 보기, N 새 일정

3내 시간표 등록

① 교시 시간 확인

  1. 오른쪽 위 ⚙(설정)을 눌러요.
  2. 교시 시간 표에서 학교 일과표와 다르면 시작·끝 시간을 고쳐요. 교시를 더하거나 뺄 수도 있어요.

② 기본 시간표 넣기

  1. 설정의 기본 시간표 표에서 칸마다 2-3 국어처럼 학반 과목을 적어요. 수업이 없는 칸은 비워 두세요.
  2. 또는 엑셀·구글 시트에서 월~금 × 교시 범위를 복사(Ctrl+C)하고, 📋 시트에서 표 붙여넣기에 붙여넣은 뒤 채우기를 눌러요. 요일 제목 줄과 교시 열이 함께 있어도 괜찮아요.

③ 하루만 바뀐 시간표 (교체·보강·결강)

  1. 일 또는 주 보기에서 바뀐 날의 시간표 칸을 눌러요.
  2. 그날의 수업을 적고 이 날만 변경을 눌러요. 수업이 없어졌으면 결강·수업 없음으로를 누르세요.
  3. 바뀐 칸은 주황색과 변경 표시로 보여요. 되돌리려면 같은 칸을 눌러 기본 시간표로 되돌리기.
자동 반영: 학사일정에 있는 재량휴업일·방학(수업 없음), 요일 교체(예: 금요일 시간표로 운영), 단축수업, 동아리 날 수업 순서 조정은 내 시간표에 저절로 반영돼요. 학사일정 때문에 바뀐 칸은 청록색과 학사·행사 표시로 보여요.

4학교 계획 연결 (주간·월중·학사일정)

우리 학교 선생님이라면

관리자가 주간 업무계획·월중 행사계획·학사일정을 미리 연결해 두었어요. 따로 할 일이 없어요. 학교 시트가 바뀌면 매일 아침 자동으로 새로 들어와요. 바로 받고 싶으면 설정 › 🔄 학교 자료 새로 받기.

다른 학교 선생님이라면 — 내 학교 시트 직접 연결

  1. 학교 구글 시트를 열고 공유 › 일반 액세스를 "링크가 있는 모든 사용자"(뷰어)로 바꿔요. (이미 그렇게 되어 있으면 그대로 두세요.)
  2. 시트 주소(브라우저 주소창의 https://docs.google.com/spreadsheets/d/…)를 복사해요.
  3. 캘린더 ⚙ 설정 › 학교 자료 › 우리 학교 시트 직접 연결의 주간 업무계획 또는 월중 행사계획 칸에 붙여넣고, 칸 밖을 한 번 눌러요.
  4. "○○건을 불러왔어요"가 뜨면 끝이에요. 이후로는 열 때마다(30분 간격) 자동으로 새로 받아요.
읽을 수 있는 시트 모양 ① 일 · 요일 · 부서1 · 부서2 … 열로 된 표 (월별·주차별로 시트가 나뉘어 있어도 됨)
② 날짜 · 내용(+ 시간, 장소·비고) 제목 줄이 있는 표
날짜 쓰는 법3(그 달의 3일), 11/3, 11.3(화), 11월 3일, 2026-11-03, 11.10~11.12(기간) 모두 알아봐요.

링크 칸을 비우면 다시 학교 기본 자료를 써요.

학사일정 (한글 파일)

  1. 학교 학사일정 한글 문서를 한글에서 다른 이름으로 저장 › .hwpx로 저장해요. (.hwp는 안 돼요)
  2. 캘린더 위쪽 📥 가져오기 › 📄 엑셀·CSV·한글(hwpx) 파일에서 그 파일을 골라요.
  3. 미리보기를 확인하고 가져오기. 수업 없는 날·요일 교체·단축수업까지 함께 반영돼요.
  4. 원래대로 돌리려면 설정 › 학사일정 › 처음 받은 학사일정으로 되돌리기.
보기 편하게: 왼쪽 부서 목록에서 필요한 부서만 켜 두면 화면이 훨씬 깔끔해요. 설정의 "주간계획이 나온 주에는 월중 행사계획을 숨기기"를 켜 두면 같은 내용이 두 번 보이지 않아요.

5내 일정 추가 · 수정 · 삭제

추가하기 (세 가지 방법)

새 일정 버튼왼쪽 위 ＋ 새 일정 › 제목·날짜·시간 입력 › 저장
달력에서월·주 보기에서 날짜 칸의 빈 곳을 누르면 그 날짜로 새 일정 창이 열려요.
빠른 추가홈·일 보기의 빠른 추가 칸에 15:30 학년 협의회처럼 쓰고 Enter. 시간이 앞에 있으면 그 시간으로, 없으면 하루 종일 일정으로 들어가요. (오후 3시 상담도 돼요)

일정 창에서 고를 수 있는 것

  • 종류: 내 일정 / 주간계획 / 학사일정 — 학교 일정을 직접 더할 수도 있어요.
  • 하루 종일, 시작·끝 시간, 여러 날이면 종료일
  • 카테고리: 업무 · 개인 · 회의·연수 (설정에서 이름·색 바꾸기, 추가 가능)
  • 반복: 매일 · 평일마다 · 매주 · 매월, 반복 종료일
  • 🙈 이 일정 숨기기: 평소엔 안 보이고, 왼쪽 "숨긴 일정도 보기"를 켜야 보여요.
  • 메모

고치기 · 지우기

  1. 달력이나 목록에서 일정을 누르면 수정 창이 열려요. 고치고 저장.
  2. 지우려면 수정 창 왼쪽 아래 삭제. 반복 일정은 "이 날만 삭제"와 "모든 반복 삭제" 중에서 골라요.
학교 시트에서 온 일정은 캘린더에서 고칠 수 없어요(학교 시트에서 고쳐야 해요). 눌러서 내 일정으로 복사하면 내 일정으로 따로 만들어 메모·시간을 바꿀 수 있어요.

6D-day · 방학 D-day

  • 방학 D-day: 홈의 날짜 아래에 "겨울방학까지 D-○○"이 크게 보여요. 학사일정의 방학식 날 기준이고, 방학 중에는 "개학까지 D-○○"로 바뀌어요.
  • D-day 목록: 학사일정에서 시험·수능·방학식·개학 같은 날을 자동으로 뽑아 줘요. 끄려면 설정 › 홈 화면 › "학사일정에서 D-day 자동으로 뽑기".
  • 내 D-day 추가: 홈의 D-day 카드 ＋ 추가 › 제목·날짜. 지우려면 줄 끝의 ×.

7자료함

  1. 홈 오른쪽 자료함의 상자(업무·수업·개인) 위로 바탕화면의 파일을 끌어다 놓으면 그 상자에 보관돼요. 한글·엑셀·PDF 등 어떤 파일이든 돼요.
  2. 보관한 파일을 누르면 열리거나 내려받아져요. 오른쪽 클릭하면 이름·메모·상자를 바꿀 수 있어요.
  3. 상자끼리 끌어서 옮길 수 있고, 웹 주소(링크)를 끌어다 놓으면 바로가기로 저장돼요.
  4. ＋ 상자로 상자를 더 만들고, 상자의 ✎로 이름·색을, 🗑로 상자를 지워요.
주의: 자료함 파일은 이 컴퓨터의 이 브라우저에만 보관돼요. 다른 컴퓨터에서는 보이지 않고, 백업 파일에도 파일 자체는 들어가지 않아요. 중요한 파일은 원본을 꼭 따로 두세요. 폴더를 끌어다 놓으면 이름과 파일 수만 기록돼요.

8수업 중 화면 가리기

  • 🙈 화면 가리기(오른쪽 위)를 누르면 캘린더 내용이 모두 사라지고 큰 시계와 날짜만 보여요. 학생들 앞에서 화면을 띄울 때 쓰세요.
  • 다시 보려면 아래의 흐릿한 📅 캘린더 보기를 누르거나 Alt+H. 가릴 때도 Alt+H.
  • 가린 채로 새로고침하거나 컴퓨터를 다시 켜도 가려진 상태로 열려요.
  • 학교 일정은 보여 주고 내 일정만 숨기려면 왼쪽 목록의 "내 일정만 가리기"를 켜요.

9배경 · 투명도

설정 › 화면에서 불투명도(반투명 정도), 배경(새벽빛·바다·숲·밤하늘·없음), 내 이미지(사진을 배경으로), 뒤 배경 흐리게(유리 효과)를 고를 수 있어요. 이 설정은 기기마다 따로 저장돼요.

10백업 · 다른 컴퓨터로 옮기기

꼭 알아 두세요: 내 시간표와 일정은 지금 쓰는 컴퓨터의 그 브라우저에만 저장돼요. 다른 사람에게는 보이지 않지만, 다른 브라우저·다른 컴퓨터에도 나타나지 않아요. 브라우저의 "쿠키 및 사이트 데이터 삭제"를 하면 함께 지워질 수 있고, 시크릿 창에서는 저장되지 않아요.

백업하기

  1. 설정 › 데이터 › 💾 백업 파일 내려받기 → school-calendar-backup-날짜.json 파일이 내려받아져요. 한 달에 한 번쯤 해 두세요.

다른 컴퓨터로 옮기기 / 되살리기

  1. 새 컴퓨터에서 캘린더를 열고 설정 › 데이터 › 백업 파일로 복원 › 백업 파일 고르기 › 복원.

11자주 묻는 질문

다른 선생님이 내 일정을 볼 수 있나요?
아니요. 내 일정·시간표는 내 브라우저에만 저장되고 인터넷 어디에도 올라가지 않아요.
"학교 자료를 불러오지 못했어요"가 떠요.
인터넷 연결을 확인하세요. 내려받은 파일을 더블클릭해 연 경우에도 이렇게 떠요. 꼭 https://… 주소로 여세요.
내 학교 시트를 연결했는데 "시트를 읽을 수 없어요"가 떠요.
시트 공유가 "링크가 있는 모든 사용자"인지 확인하세요. 학교 계정(도메인)으로만 공유된 시트는 읽을 수 없어요.
학교 일정이 두 번씩 보여요.
설정 › 학교 자료 › "주간계획이 나온 주에는 월중 행사계획을 숨기기"를 켜세요. 왼쪽 목록에서 월중 행사계획이나 주간계획 중 하나를 꺼도 돼요.
시간표가 갑자기 다르게 보여요.
학사일정에 따라 요일 교체·단축수업이 적용된 날일 수 있어요(청록색 칸). 칸을 눌러 이 날만 바꾸거나 되돌릴 수 있어요.
휴대폰에서도 쓸 수 있나요?
네, 같은 주소를 열면 돼요. 다만 휴대폰과 컴퓨터의 일정은 따로 저장돼요. 백업 파일로 옮길 수 있어요.
일정이 다 사라졌어요.
브라우저 기록 삭제나 다른 브라우저·시크릿 창일 수 있어요. 백업 파일이 있으면 설정 › 데이터 › 백업 파일로 복원으로 되살리세요.
학교 캘린더 · 사용법은 인쇄하거나 PDF로 저장해 나눠 쓸 수 있어요.
