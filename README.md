# 학교 캘린더 (동료 선생님용 웹앱)

학사일정 · 주간 업무계획 · 월중 행사계획을 한 화면에 모아 보고,
선생님마다 **자기 시간표와 개인 일정**을 넣어 쓰는 웹 캘린더예요.

- **가입 없이** 주소만 열면 바로 써요. 크롬·엣지에서는 앱처럼 설치할 수도 있어요.
- **학교 자료**(학사일정·주간계획·월중행사)는 관리자가 한 번 연결해 두면 **매일 아침 자동으로** 새로 받아요.
- **내 시간표·일정·D-day·자료함**은 각자 **자기 컴퓨터 브라우저에만** 저장돼요. 다른 선생님에게 보이지 않아요.
- 학사일정의 재량휴업일·방학, 요일 교체·단축수업, 동아리 날 수업 순서가 내 시간표에 자동으로 반영돼요.

## 폴더 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 캘린더 화면(웹앱) |
| `config.json` | **학교 설정**: 학교 이름, 학년도, 구글 시트 주소, 교시 시간, 바로가기 |
| `data/school.json` | 주간·월중 계획 (자동으로 만들어짐, 손대지 않기) |
| `data/acad.json` | 학사일정 (자동으로 만들어짐, 손대지 않기) |
| `data/academic-calendar.hwpx` | 학사일정 한글 원본 — 수정본이 나오면 이 파일만 바꿔 올리기 |
| `scripts/` | 시트·한글 파일을 읽는 프로그램 |
| `.github/workflows/` | 매일 자동으로 학교 자료를 새로 받는 설정 |
| `manifest.webmanifest`, `sw.js`, `icon*` | 앱 설치·오프라인용 |

## 관리자 처음 설정 (한 번만, 20분 정도)

### 1. GitHub 저장소 만들기
1. <https://github.com> 에 가입하고 로그인해요.
2. 오른쪽 위 **＋ › New repository**를 눌러요.
3. 이름에 `school-calendar`처럼 영어로 적고, **Public**을 고른 뒤 **Create repository**를 눌러요.

### 2. 파일 올리기
1. 받은 압축 파일을 풀어요.
2. 저장소 화면에서 **uploading an existing file**(또는 **Add file › Upload files**)을 눌러요.
3. 압축을 푼 폴더 **안의 모든 파일과 폴더**를 끌어다 놓고 **Commit changes**를 눌러요.

> ⚠️ `.github` 폴더는 이름이 점(.)으로 시작해서 숨겨져 있을 수 있어요.
> - 윈도우: 탐색기 **보기 › 숨긴 항목** 체크
> - 맥: Finder에서 `Cmd + Shift + .`
>
> 그래도 안 올라가면 GitHub에서 **Add file › Create new file**을 누르고, 이름 칸에
> `.github/workflows/update-school-data.yml` 을 그대로 적은 뒤
> 같은 이름 파일의 내용을 복사해 붙여넣고 저장하세요.

### 3. 자동 갱신이 저장할 수 있게 허락하기
1. 저장소 **Settings › Actions › General**로 가요.
2. 맨 아래 **Workflow permissions**에서 **Read and write permissions**를 고르고 **Save**를 눌러요.

### 4. 웹 주소 만들기 (GitHub Pages)
1. 저장소 **Settings › Pages**로 가요.
2. **Source**: `Deploy from a branch`, **Branch**: `main` / `/ (root)`를 고르고 **Save**를 눌러요.
3. 1~2분 뒤 위쪽에 주소가 나와요. 예: `https://내아이디.github.io/school-calendar/`
   → **이 주소를 선생님들께 나눠 주면 돼요.**

### 5. 자동 갱신 한 번 시험하기
1. 저장소 위쪽 **Actions** 탭으로 가요.
2. 처음이면 **I understand… enable them** 버튼을 눌러요.
3. 왼쪽 **학교 자료 자동 갱신 › Run workflow**를 눌러요.
4. 초록색 ✓가 뜨면 성공이에요. 이후로는 **평일 오전 6시·오후 1시**에 저절로 실행돼요.

## 학교 자료 관리

| 하고 싶은 일 | 방법 |
|---|---|
| 주간계획·월중행사가 바뀜 | 아무것도 안 해도 돼요. 구글 시트만 고치면 다음 갱신 때 반영돼요. 바로 반영하려면 **Actions › Run workflow**. |
| 학사일정 수정본이 나옴 | 한글 파일을 **.hwpx로 저장**하고 이름을 `academic-calendar.hwpx`로 바꿔서 `data` 폴더에 **덮어 올리기** (data 폴더 열기 › Add file › Upload files). 올리면 자동으로 변환돼요. 화면에 보일 제목은 `config.json`의 `acadTitle`에서 바꿔요. |
| 새 학년도 | `config.json`에서 `schoolYear`(학년도)와 시트 주소(`sheets`)를 바꾸고, 새 학사일정 hwpx를 올리세요. |
| 교시 시간·바로가기 기본값 바꾸기 | `config.json`의 `periods`, `links`를 고치세요. (이미 쓰고 있는 선생님은 각자 설정에서 고친 값이 유지돼요.) |

`config.json`은 GitHub에서 파일을 누르고 ✏️(연필)을 눌러 바로 고칠 수 있어요.
시트 주소는 `https://docs.google.com/spreadsheets/d/` **여기 부분** `/edit` 만 적으면 돼요.

**구글 시트 조건**: 공유가 **"링크가 있는 모든 사용자"**여야 자동으로 읽을 수 있어요.
(읽기만 하므로 **뷰어** 권한이면 충분해요.)

## ⚠️ 꼭 알아 두세요

- **공개 저장소라서 학교 자료가 인터넷에 공개돼요.**
  - `data/school.json`(주간계획·월중행사)과 학사일정 파일은 주소를 아는 누구나 볼 수 있어요.
  - 시트에 **학생 실명, 연락처 같은 개인정보**가 들어가지 않는지 꼭 확인하세요.
  - 공개가 곤란하면 비공개 저장소(GitHub 유료 요금제 필요)나 학교 내부 서버에 올리는 방법이 있어요.
- 지금 두 구글 시트는 **"링크가 있는 모든 사용자 = 편집자"**로 되어 있어요. 링크만 알면 누구나 고칠 수 있으니, 가능하면 시트 관리자께 **뷰어**로 바꿔 달라고 부탁하세요. 캘린더는 뷰어 권한으로도 잘 돼요.
- GitHub은 저장소에 **60일 동안 아무 변화가 없으면** 예약 실행을 멈출 수 있어요. 학교 자료가 안 바뀐다 싶으면 **Actions** 탭에서 다시 켜 주세요.
- 개인 일정은 **브라우저에만** 저장돼요. 브라우저 기록·쿠키를 지우면 함께 지워질 수 있으니 **설정 › 백업 파일 내려받기**를 가끔 해 두세요.

## 문제 해결

- **"학교 자료를 불러오지 못했어요"**: 파일을 더블클릭해 열면 안 돼요. 꼭 `https://…github.io/…` 주소로 여세요.
- **Actions가 빨간 ✗**: 실행 기록을 눌러 메시지를 보세요.
  - "내려받기 실패"·"엑셀 파일이 아니에요": 시트 공유가 "링크가 있는 모든 사용자"인지 확인하세요.
  - "Permission denied" / push 실패: 위 **3단계**(Read and write permissions)를 확인하세요.
- **새 학사일정이 반영 안 됨**: 파일 이름이 정확히 `data/academic-calendar.hwpx`인지, `.hwp`가 아니라 `.hwpx`인지 확인하세요.
